    Objeto y clase#

    Un objeto encapsula un estado (datos) y un comportamiento (operaciones). Los objetos se agrupan en clases y cada objeto es una instancia de una.

    public class Libro {
  private String titulo;
  public Libro(String titulo) { this.titulo = titulo; }
  public String getTitulo() { return titulo; }
}
Libro l = new Libro("Clean Code");

    Mensajes y métodos#

    Se envía un mensaje a un objeto con receptor.selector(argumentos); el objeto decide qué método ejecutar. A diferencia de una llamada a procedimiento, el receptor es conocido y la interpretación puede variar según su clase.

    Piensa en responsabilidades: no preguntes qué puedes hacer con tus datos, pregunta qué pueden hacer ellos por ti.
    Autoevaluación

    ¿Qué diferencia un mensaje de una llamada a función?

    El mensaje tiene receptor, y su interpretación depende de la clase de ese receptor.
