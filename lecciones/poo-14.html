    Clases abstractas, métodos virtuales y redefinición

    Jerarquías de clases: clase raíz, abstractas y redefinición de métodos.

    Módulo
    Herencia
    Lección

    Ideas clave

    • Una clase abstracta no se puede instanciar y define responsabilidades de subclase.
    • Un método abstracto debe implementarse en las subclases concretas.
    • Redefinir (@Override) cambia el comportamiento heredado.

    Clasificación jerárquica#

    Las clases se organizan en un árbol con una clase raíz (en Java, Object). Hacia abajo, las clases se vuelven más específicas.

    Clases abstractas#

    Representan un concepto abstracto para el que no tiene sentido crear instancias. Un método abstract se llama responsabilidad de subclase: toda subclase concreta debe implementarlo. Una clase con algún método abstracto debe declararse abstract.

    abstract class Cuenta {
    protected double saldo;
    abstract double interesMensual();       // responsabilidad de subclase
    void abonarIntereses() { saldo += interesMensual(); }
}
class CuentaJoven extends Cuenta {
    @Override double interesMensual() { return saldo * 0.004; }
}

    Métodos virtuales y redefinición#

    Un método es virtual si la versión que se ejecuta depende del tipo real del objeto. En Java los métodos de instancia lo son por defecto. La clase derivada redefine el comportamiento de la base con la misma firma.

    Práctica

    Declara una clase abstracta Figura con area() y dos subclases. ¿Qué pasa si una subclase no implementa area()?

    Autoevaluación

    ¿Se puede hacer new de una clase abstracta?

    No: solo de sus subclases concretas.
