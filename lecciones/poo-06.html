    Herencia y jerarquías de clases

    Organizar el conocimiento en jerarquías y reutilizar comportamiento.

    Generalización#

    En la vida real organizamos el conocimiento en jerarquías: un florista es un dependiente, que es un humano, que es un mamífero. Las clases hacen lo mismo: una subclase hereda memoria y comportamiento de sus ancestros.

    class Dependiente { void cobrar() {} }
class Florista extends Dependiente { void componerRamo() {} }
    Hereda cuando exista una relación «es un». Si no, usa composición.
    Autoevaluación

    ¿Qué hereda Florista de Dependiente?

    Sus atributos y métodos, por ejemplo cobrar().
