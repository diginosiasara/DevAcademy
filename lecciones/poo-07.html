Polimorfismo y enlace dinámico

Lección 7 de 10 · 6 min de lectura · Fuente: POO-01

En esta lección
  • Polimorfismo

Polimorfismo

Capacidad de una entidad de referenciar elementos de distinto tipo en distintos instantes. Con el enlace dinámico el método se elige en tiempo de ejecución; con el estático, en compilación.

abstract class Figura { abstract double area(); }
class Circulo extends Figura { double area() { return Math.PI * 4; } }
class Cuadrado extends Figura { double area() { return 9; } }
Figura f = new Circulo();
f.area(); // se ejecuta Circulo.area()
Autoevaluación

¿Cuándo se decide qué area() se ejecuta?

En tiempo de ejecución, según la clase real del objeto.
