    Álgebra relacional y sublenguajes SQL (DDL, DML, DCL)

    Operaciones formales sobre relaciones y su correspondencia con SQL.

    Módulo
    Bases de datos relacionales
    Lección
    64 de 82
    Lectura
    8 min
    Fuente
    UF2405 · UD4 · 4.4 y UD5

    Ideas clave

    • El álgebra relacional define operaciones sobre tablas.
    • Selección filtra filas; proyección elige columnas.
    • SQL se divide en DDL, DML, DCL y control de transacciones.

    Operaciones del álgebra relacional#

    Álgebra relacional y SQL
    OperaciónQué haceEn SQL
    SelecciónFilas que cumplen una condiciónWHERE
    ProyecciónSolo ciertas columnaslista tras SELECT
    UniónFilas de una o de otra tablaUNION
    Diferencia / intersecciónFilas en una y no en otra / en ambasEXCEPT / INTERSECT
    Producto cartesianoTodas las combinaciones de filasFROM a, b
    Concatenación (join)Producto filtrado por una condiciónJOIN ... ON
    -- Selección + proyección: nombre de los alumnos con nota notable
SELECT nombre FROM ALUMNOS WHERE nota >= 7;

    Sublenguajes de SQL#

    Sublenguajes SQL
    SublenguajeFunciónSentencias
    DQLConsultaSELECT
    DDLDefinición de datosCREATE, ALTER, DROP
    DMLManipulación de datosINSERT, UPDATE, DELETE
    DCLControl de accesoGRANT, REVOKE
    TCLTransaccionesCOMMIT, ROLLBACK
    GRANT SELECT, INSERT ON CLIENTES TO analista;
REVOKE INSERT ON CLIENTES FROM analista;
