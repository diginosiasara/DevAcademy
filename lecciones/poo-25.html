    Funciones, procedimientos y paso de parámetros

    Valor de retorno, parámetros formales y actuales, ámbito y el paso por valor de Java.

    Módulo
    Programación estructurada
    Lección
    25 de 57
    Lectura
    8 min
    Fuente
    UF2404 · UD6 · 6.3 a 6.5

    Ideas clave

    • Una función devuelve un valor; un procedimiento (void) no.
    • Java siempre pasa los argumentos por valor.
    • Con objetos se copia la referencia, no el objeto.
    En esta lección

    Funciones y procedimientos#

    Una función devuelve un valor (return); un procedimiento no devuelve nada (void). Los parámetros formales están en la declaración; los actuales son los valores con los que se llama.

    Ámbito de las variables#

    Una variable local solo existe dentro del bloque donde se declara; los atributos existen mientras exista el objeto.

    Por valor y por referencia#

    En Java el paso es siempre por valor, pero con objetos lo que se copia es la referencia: ambas referencias apuntan al mismo objeto. Por eso modificar el objeto dentro del método se ve fuera, pero reasignar la referencia no.

    static void cambiar(int n) { n = 99; }                  // no afecta fuera
static void renombrar(Persona p) { p.nombre = "Ana"; }  // sí afecta al objeto
static void reasignar(Persona p) { p = new Persona(); }  // no afecta fuera

int x = 5; cambiar(x);            // x sigue valiendo 5

    Almacenamiento de las variables#

    Las variables locales y los parámetros viven en la pila (stack) de cada llamada y desaparecen al terminar; los objetos viven en el montículo (heap). Los atributos static pertenecen a la clase y existen una sola vez.

    Dentro de una clase, las llamadas pueden ser cualificadas (otro.metodo()) o no cualificadas (metodo(), sobre la instancia actual).

    Práctica

    Escribe un método intercambiar(int a, int b) y comprueba por qué no puede intercambiar las variables del llamador.

    Autoevaluación

    Si un método reasigna su parámetro objeto, ¿cambia la variable del llamador?

    No: se pasó una copia de la referencia, y reasignarla no afecta a la original.
