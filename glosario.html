    Glosario de POO

    44 términos clave con enlace a la lección donde se explican.

    ACDEHIJLMOPRSTU

    A

    Abstracción
    Supresión intencionada de detalles para destacar los aspectos esenciales de algo. Ver lección: Abstracción y paradigmas
    Acoplamiento
    Grado de dependencia entre módulos o clases. Se busca que sea bajo. Ver lección: Modularidad: el módulo en la programación orientada a objetos
    Agregación
    Relación «todo-parte» en la que la parte puede existir sin el todo. Ver lección: Asociación, agregación y composición
    Array
    Secuencia de elementos del mismo tipo y de tamaño fijo, accesibles por índice. Ver lección: Tipos de datos y arrays
    Asociación
    Relación en la que una clase mantiene una referencia a otra para colaborar. Ver lección: Asociación, agregación y composición
    Atributo
    Variable miembro que guarda parte del estado de un objeto. Ver lección: Clases, atributos y métodos

    C

    Clase
    Plantilla que define la estructura y el comportamiento comunes de un conjunto de objetos. Ver lección: Clases, atributos y métodos
    Clase abstracta
    Clase que no se puede instanciar y que puede declarar métodos sin implementación. Ver lección: Clases abstractas, métodos virtuales y redefinición
    Cohesión
    Grado en que los elementos de un módulo tienen un propósito común. Se busca que sea alta. Ver lección: Modularidad: el módulo en la programación orientada a objetos
    Colecciones
    Estructuras dinámica de la librería de Java para guardar objetos (List, Set, Map…). Ver lección: Colecciones: listas, pilas, colas y tablas hash
    Comportamiento
    Forma en que un objeto actúa y reacciona ante los mensajes y los cambios de estado. Ver lección: Objetos: estado, comportamiento e identidad
    Composición
    Relación «todo-parte» en la que la parte no existe sin el todo. Ver lección: Asociación, agregación y composición
    Constructor
    Método especial que inicializa un objeto cuando se crea con new. Ver lección: Clases, atributos y métodos

    D

    DAO
    Data Access Object: clase que encapsula el acceso a la base de datos. Ver lección: Persistencia: del objeto a la tabla con JDBC

    E

    Encapsulación
    Ocultar la implementación de un objeto y exponer solo su interfaz. Ver lección: Encapsulación e interfaz
    Estado
    Conjunto de propiedades de un objeto con sus valores actuales. Ver lección: Objetos: estado, comportamiento e identidad
    Evento
    Objeto que describe algo ocurrido, como un clic o una tecla pulsada. Ver lección: Eventos: programar la interacción
    Excepción
    Objeto que representa una situación anómala durante la ejecución. Ver lección: Excepciones: tratar errores con objetos

    H

    Herencia
    Mecanismo por el que una subclase adquiere atributos y métodos de su superclase. Ver lección: Herencia y la regla «es-un»
    Herencia múltiple
    Herencia de varias clases a la vez; Java la sustituye por interfaces. Ver lección: Herencia múltiple e interfaces
    Hilo
    Flujo de ejecución independiente dentro de un programa (thread). Ver lección: Hilos: programación concurrente

    I

    Identidad
    Propiedad que distingue a un objeto de cualquier otro. Ver lección: Objetos: estado, comportamiento e identidad
    instanceof
    Operador que comprueba si un objeto es de un tipo determinado en ejecución. Ver lección: Objetos polimórficos y comprobación de tipos
    Interfaz
    En Java, contrato de métodos que una clase se compromete a implementar. Ver lección: Herencia múltiple e interfaces

    J

    JDBC
    API de Java para conectarse a bases de datos y ejecutar sentencias SQL. Ver lección: Persistencia: del objeto a la tabla con JDBC

    L

    Ley de Demeter
    Un método solo debe hablar con sus colaboradores directos. Ver lección: Constructores, protected y acoplamiento en la herencia
    Ligadura dinámica
    Selección del método a ejecutar en tiempo de ejecución según la clase real del objeto. Ver lección: Enlace estático y dinámico: sobrecarga y sobrescritura

    M

    Mensaje
    Petición enviada a un objeto receptor para que ejecute una operación. Ver lección: Mensajes y tipos de métodos
    Método
    Función miembro que define una operación que puede realizar un objeto. Ver lección: Clases, atributos y métodos
    Método estático
    Método que pertenece a la clase y no necesita una instancia. Ver lección: Mensajes y tipos de métodos
    Modularidad
    Descomposición de un sistema en módulos cohesivos y débilmente acoplados. Ver lección: Modularidad: el módulo en la programación orientada a objetos

    O

    Objeto
    Instancia de una clase con estado, comportamiento e identidad. Ver lección: Objetos: estado, comportamiento e identidad

    P

    Paradigma
    Forma de entender y organizar la programación (estructurada, OO, funcional…). Ver lección: Abstracción y paradigmas
    Paso por valor
    Se copia el argumento; en Java con objetos se copia la referencia. Ver lección: Funciones, procedimientos y paso de parámetros
    Persistencia
    Capacidad de un objeto de trascender en el tiempo, por ejemplo guardado en una base de datos. Ver lección: Persistencia: del objeto a la tabla con JDBC
    Polimorfismo
    Capacidad de una entidad de referenciar elementos de distinto tipo. Ver lección: Polimorfismo: concepto y tipos

    R

    Recolector de basura
    Proceso de la JVM que libera la memoria de los objetos inalcanzables. Ver lección: Gestión de memoria y recolector de basura

    S

    Sobrecarga
    Varios métodos con el mismo nombre y distintos parámetros; se resuelve al compilar. Ver lección: Enlace estático y dinámico: sobrecarga y sobrescritura
    Sobrescritura
    Redefinición en una subclase de un método heredado con la misma firma. Ver lección: Enlace estático y dinámico: sobrecarga y sobrescritura
    Socket
    Extremo de una comunicación en red entre cliente y servidor. Ver lección: Programación en red y acceso a bases de datos
    SQL
    Lenguaje estándar para definir y consultar bases de datos relacionales. Ver lección: Modelo relacional y SQL básico
    Superclase
    Clase de la que otra hereda; la que hereda es la subclase. Ver lección: Herencia y la regla «es-un»

    T

    this
    Referencia a la instancia actual dentro de un método. Ver lección: Clases, atributos y métodos

    U

    UML
    Lenguaje Unificado de Modelado, notación estándar para el análisis y diseño OO. Ver lección: Lenguajes orientados a objetos: tipos y comparación
