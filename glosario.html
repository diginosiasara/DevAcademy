    Glosario de POO

    118 términos clave con enlace a la lección donde se explican.

    AÁBCDEFHIJLMNOPRSTUV

    A

    Abstracción
    Supresión intencionada de detalles para destacar los aspectos esenciales de algo. Ver lección: Abstracción y paradigmas
    ACID
    Atomicidad, consistencia, aislamiento y durabilidad: propiedades de una transacción. Ver lección: Procedimientos almacenados y transacciones
    Acoplamiento
    Grado de dependencia entre módulos o clases. Se busca que sea bajo. Ver lección: Modularidad: el módulo en la programación orientada a objetos
    Adaptador
    Clase con los métodos de un oyente implementados en vacío. Ver lección: Eventos: programar la interacción
    Agregación
    Relación «todo-parte» en la que la parte puede existir sin el todo. Ver lección: Asociación, agregación y composición
    Array
    Secuencia de elementos del mismo tipo y de tamaño fijo, accesibles por índice. Ver lección: Tipos de datos y arrays
    Asociación
    Relación en la que una clase mantiene una referencia a otra para colaborar. Ver lección: Asociación, agregación y composición
    Atributo
    Variable miembro que guarda parte del estado de un objeto. Ver lección: Clases, atributos y métodos
    Autoboxing
    Conversión automática entre un tipo primitivo y su clase envoltorio. Ver lección: Tipos de datos y clases: primitivos, envoltorios y String

    Á

    Álgebra relacional
    Conjunto de operaciones formales sobre relaciones: selección, proyección, unión, join… Ver lección: Álgebra relacional y sublenguajes SQL (DDL, DML, DCL)
    Ámbito
    Zona del programa donde una variable existe y es accesible. Ver lección: Ámbito de las variables y constantes

    B

    Bytecode
    Código intermedio que genera javac y ejecuta la JVM. Ver lección: El lenguaje Java: características, comentarios e identificadores

    C

    Caja blanca
    Prueba que examina la estructura interna y los caminos lógicos del código. Ver lección: Tipos de pruebas: caja negra, caja blanca y JUnit
    Caja negra
    Prueba que examina solo entradas y salidas, sin mirar el código. Ver lección: Tipos de pruebas: caja negra, caja blanca y JUnit
    Camino crítico
    Ruta más larga de actividades sin holgura en un diagrama PERT; fija la duración mínima del proyecto. Ver lección: Planificación y seguimiento: estimación, PERT y Gantt
    Cardinalidad
    Número de entidades con las que otra puede asociarse a través de una relación. Ver lección: Diseño de bases de datos: modelo entidad-relación
    CASE
    Herramientas de ingeniería del software asistida por ordenador (Upper, Lower e I-CASE). Ver lección: Proceso de ingeniería del software: fases, modelos y metodologías
    Cast
    Conversión explícita de un tipo a otro, que puede perder información. Ver lección: Tipos simples, literales y conversión de tipos
    Clase
    Plantilla que define la estructura y el comportamiento comunes de un conjunto de objetos. Ver lección: Clases, atributos y métodos
    Clase abstracta
    Clase que no se puede instanciar y que puede declarar métodos sin implementación. Ver lección: Clases abstractas, métodos virtuales y redefinición
    Clave ajena
    Columna que referencia la clave primaria de otra tabla. Ver lección: Bases de datos relacionales: conceptos y claves
    Clave primaria
    Columna o conjunto de columnas que identifican de forma única cada fila. Ver lección: Bases de datos relacionales: conceptos y claves
    Cliente ligero
    Cliente que solo presenta la interfaz, como un navegador web. Ver lección: Arquitectura web: cliente ligero y servidores
    CMM
    Modelo de madurez de procesos con cinco niveles inclusivos: Inicial, Repetible, Definido, Gestionado y Optimizado. Ver lección: Calidad del software: modelos, métricas y madurez
    COCOMO
    Modelo de estimación de costes de Boehm: esfuerzo = a · KLOC^b, con modos orgánico, semiacoplado y empotrado. Ver lección: Planificación y seguimiento: estimación, PERT y Gantt
    Cohesión
    Grado en que los elementos de un módulo tienen un propósito común. Se busca que sea alta. Ver lección: Modularidad: el módulo en la programación orientada a objetos
    Colecciones
    Estructuras dinámica de la librería de Java para guardar objetos (List, Set, Map…). Ver lección: Colecciones: listas, pilas, colas y tablas hash
    Comparator
    Objeto que define un criterio de ordenación entre elementos. Ver lección: java.util en detalle: Collection, Iterator, Comparator y Map
    Complejidad
    Número de caminos lógicos de una unidad de código. Ver lección: Calidad del código y buenas prácticas
    Comportamiento
    Forma en que un objeto actúa y reacciona ante los mensajes y los cambios de estado. Ver lección: Objetos: estado, comportamiento e identidad
    Composición
    Relación «todo-parte» en la que la parte no existe sin el todo. Ver lección: Asociación, agregación y composición
    Constante
    Valor que no cambia tras asignarse; en Java, una variable final. Ver lección: Ámbito de las variables y constantes
    Constructor
    Método especial que inicializa un objeto cuando se crea con new. Ver lección: Clases, atributos y métodos

    D

    DAO
    Data Access Object: clase que encapsula el acceso a la base de datos. Ver lección: Persistencia de objetos con el patrón DAO
    DCL
    Lenguaje de control de datos: GRANT y REVOKE. Ver lección: Álgebra relacional y sublenguajes SQL (DDL, DML, DCL)
    DDL
    Lenguaje de definición de datos: CREATE, ALTER, DROP, TRUNCATE. Ver lección: Lenguaje de definición de datos (DDL)
    Deuda técnica
    Coste acumulado por no mantener bien el código; se relaciona con la mantenibilidad. Ver lección: Calidad del software: modelos, métricas y madurez
    DML
    Lenguaje de manipulación de datos: SELECT, INSERT, UPDATE, DELETE. Ver lección: Lenguaje de manipulación de datos (DML)
    DNS
    Servicio que traduce nombres de dominio en direcciones IP. Ver lección: Protocolos y tecnologías de la web
    Driver
    Controlador que traduce las llamadas de la API al protocolo de un SGBD. Ver lección: Acceso a datos: API, controladores y conexión

    E

    Encapsulación
    Ocultar la implementación de un objeto y exponer solo su interfaz. Ver lección: Encapsulación e interfaz
    Entidad
    Objeto del mundo real distinguible, descrito por atributos, en el modelo E-R. Ver lección: Diseño de bases de datos: modelo entidad-relación
    Entidad débil
    Entidad sin clave propia que depende de otra fuerte. Ver lección: Del modelo entidad-relación al modelo relacional
    Estado
    Conjunto de propiedades de un objeto con sus valores actuales. Ver lección: Objetos: estado, comportamiento e identidad
    Evento
    Objeto que describe algo ocurrido, como un clic o una tecla pulsada. Ver lección: Eventos: programar la interacción
    Excepción
    Objeto que representa una situación anómala durante la ejecución. Ver lección: Excepciones: tratar errores con objetos
    Extensibilidad
    Facilidad para ampliar una aplicación gracias a la modularidad y la herencia. Ver lección: Ventajas, desventajas y clasificación de los lenguajes OO

    F

    Fichero
    Almacenamiento persistente de datos en disco. Ver lección: Ficheros: leer y escribir datos
    Flexibilidad
    Las clases son módulos independientes a partir de los cuales se definen otras nuevas. Ver lección: Ventajas, desventajas y clasificación de los lenguajes OO

    H

    Herencia
    Mecanismo por el que una subclase adquiere atributos y métodos de su superclase. Ver lección: Herencia y la regla «es-un»
    Herencia múltiple
    Herencia de varias clases a la vez; Java la sustituye por interfaces. Ver lección: Herencia múltiple e interfaces
    Hilo
    Flujo de ejecución independiente dentro de un programa (thread). Ver lección: Hilos: concurrencia, estados y sincronización
    HTTP
    Protocolo de aplicación de la web: peticiones y respuestas entre navegador y servidor. Ver lección: Protocolos y tecnologías de la web

    I

    IDE
    Entorno integrado de desarrollo: editor, compilador, depurador y pruebas. Ver lección: Elegir lenguaje, tipos de aplicaciones y entorno de desarrollo
    Identidad
    Propiedad que distingue a un objeto de cualquier otro. Ver lección: Objetos: estado, comportamiento e identidad
    instanceof
    Operador que comprueba si un objeto es de un tipo determinado en ejecución. Ver lección: Objetos polimórficos y comprobación de tipos
    Interfaz
    En Java, contrato de métodos que una clase se compromete a implementar. Ver lección: Herencia múltiple e interfaces
    Iterator
    Objeto que recorre los elementos de una colección. Ver lección: java.util en detalle: Collection, Iterator, Comparator y Map

    J

    JavaBean
    Clase con constructor vacío, atributos privados y accesores get/set. Ver lección: Estándares de facto y componentes orientados a objetos
    Javadoc
    Herramienta que genera documentación a partir de comentarios /** */. Ver lección: El lenguaje Java: características, comentarios e identificadores
    Javadoc
    Herramienta que genera documentación HTML a partir de los comentarios del código Java. Ver lección: Documentación del software
    JDBC
    API de Java para conectarse a bases de datos y ejecutar sentencias SQL. Ver lección: Acceso a datos: API, controladores y conexión
    JDK
    Kit de desarrollo de Java: compilador, máquina virtual y herramientas. Ver lección: Elegir lenguaje, tipos de aplicaciones y entorno de desarrollo
    JOIN
    Combinación de filas de dos o más tablas mediante una condición. Ver lección: JOIN, UNION y subconsultas
    JUnit
    Marco de pruebas unitarias para Java; las clases de prueba se nombran NombreClaseTest. Ver lección: Tipos de pruebas: caja negra, caja blanca y JUnit

    L

    Layout
    Gestor de diseño que coloca los componentes dentro de un contenedor. Ver lección: Componentes gráficos: AWT y Swing
    Ley de Demeter
    Un método solo debe hablar con sus colaboradores directos. Ver lección: Constructores, protected y acoplamiento en la herencia
    Ligadura dinámica
    Selección del método a ejecutar en tiempo de ejecución según la clase real del objeto. Ver lección: Enlace estático y dinámico: sobrecarga y sobrescritura
    Listener
    Oyente registrado en una fuente de eventos para atenderlos. Ver lección: Eventos: programar la interacción
    Lógica de negocio
    Reglas propias del dominio de la aplicación. Ver lección: Diseño de arquitecturas y lógica de negocio

    M

    Mantenibilidad
    Facilidad para corregir o modificar una clase sin afectar a las demás. Ver lección: Ventajas, desventajas y clasificación de los lenguajes OO
    Mensaje
    Petición enviada a un objeto receptor para que ejecute una operación. Ver lección: Mensajes y tipos de métodos
    Método
    Función miembro que define una operación que puede realizar un objeto. Ver lección: Clases, atributos y métodos
    Método estático
    Método que pertenece a la clase y no necesita una instancia. Ver lección: Mensajes y tipos de métodos
    Modularidad
    Descomposición de un sistema en módulos cohesivos y débilmente acoplados. Ver lección: Modularidad: el módulo en la programación orientada a objetos
    MVC
    Patrón que separa modelo, vista y controlador. Ver lección: Diseño de arquitecturas y lógica de negocio

    N

    Navegador
    Aplicación cliente que interpreta documentos web y los muestra al usuario. Ver lección: Arquitectura web: cliente ligero y servidores
    Normalización
    Proceso de organizar las tablas para eliminar redundancias. Ver lección: Diseño de bases de datos: modelo entidad-relación
    NULL
    Marca de valor desconocido; se comprueba con IS NULL. Ver lección: Tipos de datos SQL, valores nulos y SQL embebido

    O

    Objeto
    Instancia de una clase con estado, comportamiento e identidad. Ver lección: Objetos: estado, comportamiento e identidad
    Ocultación de información
    Cada objeto se aísla del exterior y expone solo una interfaz. Ver lección: Encapsulación e interfaz
    Operador
    Símbolo que realiza una operación sobre uno o más operandos. Ver lección: Operadores y expresiones
    ORM
    Mapeo objeto-relacional: correspondencia automática entre clases y tablas. Ver lección: Del modelo relacional al modelo de objetos

    P

    Paquete
    Agrupación de clases relacionadas (package) en una librería. Ver lección: Librerías de clases: paquetes, import y JAR
    Paradigma
    Forma de entender y organizar la programación (estructurada, OO, funcional…). Ver lección: Abstracción y paradigmas
    Paso por valor
    Se copia el argumento; en Java con objetos se copia la referencia. Ver lección: Funciones, procedimientos y paso de parámetros
    Persistencia
    Capacidad de un objeto de trascender en el tiempo, por ejemplo guardado en una base de datos. Ver lección: Persistencia de objetos con el patrón DAO
    Polimorfismo
    Capacidad de una entidad de referenciar elementos de distinto tipo. Ver lección: Polimorfismo: concepto y tipos
    Procedimiento almacenado
    Conjunto de sentencias SQL guardado en el servidor y ejecutable por nombre. Ver lección: Procedimientos almacenados y transacciones
    Puntos de función
    Medida del tamaño funcional del software desde el punto de vista del usuario (Albrecht, IBM, 1979). Ver lección: Planificación y seguimiento: estimación, PERT y Gantt

    R

    Recolector de basura
    Proceso de la JVM que libera la memoria de los objetos inalcanzables. Ver lección: Gestión de memoria y recolector de basura
    Refactorización
    Cambiar la estructura interna del código sin alterar su comportamiento. Ver lección: Calidad del código y buenas prácticas
    Reflexión
    Capacidad de un programa de examinar y usar sus propias clases y métodos en ejecución. Ver lección: Reflexión: invocar métodos en tiempo de ejecución
    Reglas de Codd
    Doce reglas que debe cumplir un sistema para ser considerado relacional. Ver lección: Modelos de datos y las doce reglas de Codd
    Reusabilidad
    Posibilidad de utilizar una clase ya definida en otras aplicaciones. Ver lección: Ventajas, desventajas y clasificación de los lenguajes OO
    Robustez
    Detección temprana de errores mediante comprobaciones en compilación y en ejecución. Ver lección: Java frente a C++: qué cambia

    S

    Scrum
    Metodología ágil basada en sprints, roles definidos y reuniones diarias. Ver lección: Metodologías: RUP, XP, Scrum y prácticas ágiles
    Serialización
    Conversión de un objeto en una secuencia de bytes para guardarlo o enviarlo. Ver lección: Ficheros: leer y escribir datos
    Servidor web
    Servidor que aloja sitios y aplicaciones web y atiende peticiones HTTP. Ver lección: Arquitectura web: cliente ligero y servidores
    Servlet
    Clase Java que atiende peticiones HTTP en un contenedor como Tomcat. Ver lección: Lenguajes de servidor: Servlets, JSP, PHP y ASP
    SGBD
    Sistema gestor de bases de datos: software que administra los datos. Ver lección: Bases de datos relacionales: conceptos y claves
    Sobrecarga
    Varios métodos con el mismo nombre y distintos parámetros; se resuelve al compilar. Ver lección: Enlace estático y dinámico: sobrecarga y sobrescritura
    Sobrescritura
    Redefinición en una subclase de un método heredado con la misma firma. Ver lección: Enlace estático y dinámico: sobrecarga y sobrescritura
    Socket
    Extremo de una comunicación en red entre cliente y servidor. Ver lección: Programación en red: cliente-servidor y sockets
    SQL
    Lenguaje estándar para definir y consultar bases de datos relacionales. Ver lección: Lenguaje de manipulación de datos (DML)
    SQL embebido
    SQL incrustado en un lenguaje anfitrión que traduce un precompilador. Ver lección: Tipos de datos SQL, valores nulos y SQL embebido
    Superclase
    Clase de la que otra hereda; la que hereda es la subclase. Ver lección: Herencia y la regla «es-un»
    Swing
    Librería de componentes gráficos de Java (JFrame, JButton…). Ver lección: Componentes gráficos: AWT y Swing

    T

    TCP/IP
    Pila de protocolos base de Internet. Ver lección: Protocolos y tecnologías de la web
    TDD
    Desarrollo guiado por pruebas: primero la prueba, después el código. Ver lección: Metodologías: RUP, XP, Scrum y prácticas ágiles
    this
    Referencia a la instancia actual dentro de un método. Ver lección: Clases, atributos y métodos
    Transacción
    Conjunto de operaciones que se confirman o se deshacen como una unidad. Ver lección: Procedimientos almacenados y transacciones
    Trazabilidad
    Capacidad de rastrear un elemento (requisito, diseño, código) hasta su origen a lo largo de las fases. Ver lección: Proceso de ingeniería del software: fases, modelos y metodologías
    Trigger
    Disparador: procedimiento que se ejecuta ante un INSERT, UPDATE o DELETE. Ver lección: DDL avanzado: vistas, disparadores, procedimientos, ALTER y DROP

    U

    UML
    Lenguaje Unificado de Modelado, notación estándar para el análisis y diseño OO. Ver lección: Lenguajes orientados a objetos: tipos y comparación
    UML
    Lenguaje de modelado de Booch, Jacobson y Rumbaugh; en su versión 2.x define 14 diagramas. Ver lección: Diagramado con UML
    URL
    Dirección que localiza un recurso en la red: protocolo, servidor y ruta. Ver lección: Protocolos y tecnologías de la web

    V

    Vista
    Tabla virtual cuyo contenido es el resultado de una consulta. Ver lección: Lenguaje de definición de datos (DDL)
